# Coding Checklist

Every Pull Request must satisfy:

* [ ] No hardcoded values
* [ ] Inspector configurable
* [ ] XML comments
* [ ] Null checks
* [ ] No duplicated code
* [ ] Modular architecture
* [ ] Clean Inspector
* [ ] Production-ready

---

# Definition of Done

A feature is considered complete only if:

* Gameplay works.
* Inspector is configurable.
* No Console errors.
* No memory leaks.
* Compatible with unlimited rooms.
* Compatible with unlimited anomalies.
* Code follows architecture.
* UI integrated.
* Tested in Play Mode.
